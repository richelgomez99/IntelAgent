## 🎓 SpecKit Workflow Recap

\`\`\`
1️⃣  SPECIFY → Write feature spec (what to build)
              User stories + acceptance criteria + metrics
              File: specs/spec-NNN-{feature}.md

2️⃣  PLAN    → Generate implementation plan (how to build)
              Steps + files + decisions + tests
              File: specs/plan-NNN.md

3️⃣  TASKS   → Generate task breakdown (actionable steps)
              Numbered tasks + dependencies + estimates
              File: specs/tasks-NNN.md

4️⃣  EXECUTE → Build feature (follow constitution)
              69 rules enforced on every commit
              Output: Production-ready feature
\`\`\`
